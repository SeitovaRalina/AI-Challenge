# День 5. Версии моделей

Выполните один и тот же запрос:
👉 на слабой модели
👉 на средней модели
👉 на сильной модели

(например: из начала, середины и конца списка HuggingFace). Но если в API
несколько моделей, то можно выбрать из них.

Замерьте:
👉 время ответа
👉 количество токенов
👉 стоимость (если модель платная)

Сравните:
👉 качество ответов
👉 скорость
👉 ресурсоёмкость
